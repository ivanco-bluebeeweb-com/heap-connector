# Heap Analytics Connector — Preparation

**Category:** C40. Product Analytics & Behavioral  
**Status:** App Preparation Complete (Genuinely Vendor-Specific)  
**Standard:** APP_PREPARATION_STANDARD.md

## 1. Паспорт коннектора
- **Название:** Heap Analytics Connector (`heap-connector`)
- **Официальный портал вендора:** https://heap.io
- **Базовый API:** `https://heapanalytics.com/api`
- **Модель аутентификации:** Heap App ID + Environment API Key
- **Назначение:** Интеграция платформы Imperal Cloud с Heap Analytics для автоматизации предметной области: автоматический автозахват кликов и событий интерфейса без предварительной ручной разметки кода.

## 2. Решаемая проблема
Когда **продуктовый аналитик** сталкивается с задачей **автоматический автозахват кликов и событий интерфейса без предварительной ручной разметки кода**, возникает необходимость ручного мониторинга, дублирования статусов и переключения между окнами. Это приводит к потере времени, замедлению реакции на инциденты и ошибкам ручного ввода.

## 3. Роли и права доступа
- **продуктовый аналитик, UX-исследователь**
- Принцип наименьших привилегий (Least Privilege): токен запрашивает доступ только к разрешенным операциям чтения и подтвержденным действиям.

## 4. Ключевые сущности
определения событий (/event_definitions), сегменты (/segments), свойства пользователей (/user_properties)

## 5. Первичный рабочий сценарий
`чтение виртуальных событий -> сопоставление с воронками -> передача когорт в ретаргетинг`.

## 6. Границы коннектора
- Изолированное хранение секретов (BYOC).
- Никаких фиктивных методов сторонних предметных областей.
- Деструктивные операции требуют явного подтверждения пользователя.
